# haquenam.github.io

This repository powers the public GitHub Pages site for Enam.

Live site address:

https://haquenam.github.io

## Purpose

This repository is intended to act as a public portfolio and learning hub.

It can be used to showcase:

* Public learning projects
* GitHub repositories
* Books and articles
* Bangla technology learning resources
* Cybersecurity 101 materials
* AI Integrator learning materials
* Public safe ServiceNow architecture notes

## Important Governance Note

Do not upload confidential client content, internal project material, commercial delivery artefacts, personal documents, credentials, API keys, or restricted files to this repository.

Only public safe content should be published here.

## How To Publish

1. Open the repository on GitHub.
2. Upload these files to the root of the repository.
3. Commit the changes to the `main` branch.
4. Go to Settings.
5. Open Pages.
6. Confirm that GitHub Pages is publishing from the `main` branch and root folder.
7. Visit https://haquenam.github.io after a few minutes.
