# Privacy

The application uses only static HTML, CSS and JavaScript. No authentication, third party telemetry, artificial intelligence model, remote database or assessment submission service is built into the application.

Answers and calculations remain in the browser page. Exported JSON snapshots and browser generated PDF files are saved to the visitor's own device and are shared only if the visitor chooses to share them. Unsaved data is lost when the page is refreshed.

Avoid entering credentials, confidential production records, sensitive details or raw CMDB exports.

The site is delivered by GitHub Pages, whose ordinary network and security processing may record visitor IP addresses and access information. Documentation links open external sources under their own privacy practices.
