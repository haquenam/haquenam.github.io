# Rihan's Market Rush
A browser-based supermarket arcade/tycoon fan game. Built with care for Rihan by his uncle Enamul Haque.

## Play
Live (public-safe) game: https://haquenam.github.io/rihans-market-rush/

Open the link on a desktop or mobile browser. No installation, sign-in, account or game server. The site has no analytics or backend in this game.

## Game modes and goals
- **PLAY / EXPLORE:** press Start Shift. Control Rihan with WASD or arrows. Move beside a product shelf and press **E** to collect items in his shopping quest. Go to Checkout and press E to submit the completed quest. Press E near a waiting shopper to fast-scan and earn tips.
- **BUILD THE STORE:** choose a department on the left, click an empty square to build it. Right-click a shelf to sell it for half its original cost. Aisles must remain accessible.
- **RESTOCK SHELVES:** select the relevant product department, then click its shelf. Each order supplies up to 3 units using shop cash.
- **Progress:** clear five increasingly difficult timed shifts by reaching the sales target and keeping reputation above the threshold. Earn stars, cash, upgrades and achievements.
- **Difficulty:** Normal or Expert when starting a new game.
- **Pause:** P or the Pause button.
- **Reset:** New Game / Reset at the bottom. Confirm to erase local gameplay progress. The saved avatar is independent and can be removed separately.

## Rihan's private avatar
The public repository **does not include Rihan's real photographs**. Select **Add Rihan's photo** inside the game and choose the image on your own device. The browser resizes it, stores it in localStorage on that device, and shows it on Rihan's game character. It is not sent to GitHub or a server. Do not use public computers or shared browser profiles with personal photographs.

An optional **private family package** can contain assets/rihan-avatar.png for automatic local use. Never commit that asset to this public repository without parental consent and an explicit decision about public distribution.

## Technical
Vanilla HTML, CSS, JavaScript and Canvas 2D. No third-party libraries, remote scripts or trackers. Progress and custom avatar use browser localStorage. Hosting is static, through GitHub Pages.

The game is a modest independent browser title, not a Roblox/PlayStation-scale 3D game. Its five days last around 7–8 minutes of shift time, plus additional exploration and building.
